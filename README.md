# جمعية أفانين — الموقع الجديد

نسخة مراجعة مستقلة عن الموقع القديم، مبنية بصفحات HTML/CSS/JS مع خط Alexandria والأصول المحلية.

- `index.html`: الواجهة الرئيسية.
- `contact.html`: التواصل والعنوان.
- `privacy.html`: مسودة سياسة الخصوصية تتطلب اعتمادًا نظاميًا.
- `careers.html`: التوظيف.

**تنبيه:** هذه نسخة معاينة ولا تعد موقعًا جاهزًا للإطلاق؛ الروابط الموسومة قيد التجهيز، ووثائق الحوكمة وروابط حسابات التواصل والعنوان الرسمي تحتاج استكمالًا. لا تربط النطاق الرسمي قبل إغلاق فجوات المحتوى والوظائف. متجر سلة مستقل وغير مربوط.

لا توجد أي وصلة تقنية بالموقع السابق أو بمنظومة رافد.
