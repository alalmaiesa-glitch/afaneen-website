# موقع جمعية أفانين — النسخة التجريبية المستقلة

موقع مستقل تماماً دون أي ربط تقني بالنظام القديم. يضم الصفحات التالية:

- `index.html` الصفحة الرئيسية بالتصميم المعتمد.
- `about.html` نبذة عن الجمعية والرؤية والرسالة (بانتظار النص الرسمي).
- `governance.html` الشفافية والبيانات النظامية ومجلس الإدارة واللوائح والتقارير (حالة الوثائق واضحة، لا مستندات مختلقة).
- `services.html` صفحة الخدمات، `volunteering.html` فرص التطوع، `programs.html` البرامج، `membership.html` خدمات العضوية.
- `media.html` الأخبار والمكتبات، و`partners.html` شركاء النجاح.
- `contact.html` العنوان والتواصل، و`privacy.html` مسودة سياسة الخصوصية، و`careers.html` التوظيف.

## الوضع الحالي

**تجريبي غير جاهز للنطاق الرسمي.** لا توجد استمارات تسجيل، ولا متجر دعم متصل، ولا روابط حسابات اجتماعية مفترضة. الوثائق القانونية والبيانات الرسمية التي لم تُقدّم للجمعية بشكل موثق تظهر في قائمة انتظار الاستكمال ولا يجوز اعتبارها منشورة. الروابط الداخلية تعمل إلى صفحات محلية. يظل `noindex,nofollow` و`robots.txt` مغلقاً للفهرسة حتى الاعتماد النهائي.

## التشغيل والنقل

استضافة ثابتة مباشرة بلا قاعدة بيانات أو خدمة خارجية أو خطوة بناء. الملفات تحت `/assets` مملوكة للمشروع وينبغي حفظ مصادرها وتراخيصها. يلزم مراجعة حقوق استخدام الشعار والصورة والخط قبل إعادة التوزيع. للنقل، يمكن نشر المجلد في أي خدمة استضافة صفحات ثابتة دون ربط تقني بـVercel. لا يُضاف نظام بيانات أو لوحات إدارة إلا عند حاجة تشغيلية معتمدة.

## قاعدة التدقيق العربي

يعتمد هذا الموقع موضع تنوين الفتح على الألف النهائية: «ترفاً»، «لغوياً»، «مستقلاً». لا يوضع التنوين على الحرف السابق لألف التنوين في النصوص الجديدة. ولا يشمل هذا التحويل الكلمات التي لا تنتهي بألف التنوين، مثل «لغةً» أو «بناءً».
